# 弹珠

这是一个可玩的霓虹机关弹球游戏：玩家从 A 点发射器发射小球，通过墙壁反弹、传送门和障碍物，让球碰到 B 点目标。

**当前版本：v0.1.0**

## 在线试玩

直接打开这个网址即可试玩：

```text
https://kreezhu.github.io/marble_demo/
```


## 玩法

- 开局由 A1 持有球；空发射器必须先接到球，才能被选择、瞄准和发射。
- 调整方向，也可以直接在画布上拖动来瞄准；所有发射器力度固定为 700。
- 点击“发射”，观察弹道、反弹和传送。
- 点击“重置”重新尝试当前关卡。
- 用左右箭头切换关卡，空格发射，R 重置。

## 当前内容

- 25 个递进关卡；关卡菜单固定为每行 5 关，并使用可滚动列表容纳后续新增关卡。
- 统一的“霓虹工业机库”美术：深色金属、功能色灯带、工业地板和机械机关材质。
- 前期以单个 A1 发射器为主，后期加入初始为空的 R 发射器。
- 可调方向，力度固定为 700。
- 墙壁反弹。
- 静态障碍和移动障碍。
- 成对传送门。
- 弹道预览。
- 命中 B 点后的成功状态。
- 发射、碰撞、传送和命中的短音效。
- 命中成功后的扩散环、粒子效果和进入下一关提示。
- 球只要碰到 B 点就立即通关；墙壁、传送门、开关门和发射器都是可选路线元素，不是胜利条件。
- 同一颗球进入任意 A 或 R 发射器后都会停下；该发射器变为有球状态，玩家重新瞄准后手动二次发射，已经打开的门会保持开启。
- 空发射器不显示预线，也不能提前调整；编辑器为方便关卡设计，会额外显示所有发射器的设计预线。
- 球停下或被卸力区域吸住时会立即重置开关、门、移动机关和 A1 持球状态，同时保留上一发的失败轨迹供参考。

## 关卡设计

1. 1-5 关：直线、斜线、平面和曲面反弹、绿色弹力墙。
2. 6-9 关：传送门、中继换向和移动窗口。
3. 10-15 关：红色开关门、回收再发射和多阶段连锁。
4. 16-25 关：窄廊开锁、曲面钥匙、传送认证、中继通电和完整单球挑战。

## 验证

核心规则有自动测试，覆盖墙面反弹、B 点穿越命中、传送门、任意发射器接球、失败后的尝试复位、移动障碍、通关提示、25 关推荐路线，以及每个障碍和道具的作用标注。
