# 弹球箱庭 Demo

这是一个可玩的浏览器 demo：玩家从 A 点发射器发射小球，通过墙壁反弹、传送门和障碍物，让球碰到 B 点目标。

## 打开方式

本地服务已经启动在：

```text
http://127.0.0.1:8000/index.html
```

也可以在这个目录里启动任意静态文件服务器后打开 `index.html`。

## 玩法

- 选择 A1、A2、A3 等发射器。
- 调整方向和力度，也可以直接在画布上拖动来瞄准。
- 点击“发射”，观察弹道、反弹和传送。
- 点击“重置”重新尝试当前关卡。
- 用左右箭头切换关卡，空格发射，R 重置。

## 当前内容

- 10 个递进关卡。
- 多个可选发射器。
- 可调方向和力度。
- 墙壁反弹。
- 静态障碍和移动障碍。
- 成对传送门。
- 弹道预览。
- 命中 B 点后的成功状态。
- 发射、碰撞、传送和命中的短音效。
- 命中成功后的扩散环、粒子效果和进入下一关提示。
- 关卡会检查必要机制；碰到 B 点但没用到本关要求的墙弹、传送或移动障碍等关键机制，不会直接通关。
- 发射器选择是关卡训练目标，不是硬性通关锁；如果你用别的发射器打出有效路线，仍然算成功。

## 关卡设计

1. 直线校准：基础瞄准。
2. 上墙折返：单墙反弹。
3. 下墙折返：反射角判断。
4. 窄门力度：力度控制。
5. 双发射器选择：选择正确起点。
6. 传送入门：传送门基础，并在出门后利用墙面修正。
7. 传送折返：传送与反弹组合。
8. 移动节奏：移动障碍时机和非水平反弹路线。
9. 三点取舍：路线规划。
10. 终局箱庭：综合判断。

## 验证

核心规则有自动测试，覆盖墙面反弹、目标穿越命中、传送门、移动障碍、传送后的误判保护、通关后下一关提示文案、关卡机制使用情况，以及每个障碍/道具的作用标注。
