# Project Safeguards

- Do not modify existing official level definitions in `src/levels.js` unless the user gives explicit permission for those specific levels.
- Do not modify or migrate saved custom-level content unless the user explicitly requests it.
- New level-design ideas must be implemented as newly appended levels, not by rewriting existing authored levels.
- Global gameplay, UI, editor, documentation, and test changes must preserve existing level names, layouts, coordinates, objects, and recommended routes unless explicit level-edit permission is provided.
